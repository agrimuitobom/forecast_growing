# 🌱 作物生育予測アプリ

気温データとAIを使って、作物の収穫時期を予測するWebアプリケーションです。

## 機能

- 📸 **画像分析**: Gemini AIが作物の画像から種類、成長段階、健康状態を分析
- 🌡️ **気象データ統合**: Open-Meteo APIで過去7日間と今後7日間の気温・湿度データを取得（完全無料）
- 🔮 **収穫予測**: AIが気象データと生育状況から収穫時期を予測
- 📍 **位置情報対応**: GPS自動取得または手動入力に対応
- 📊 **視覚化**: 気温推移のグラフ表示
- 🌾 **複数作物対応**: さまざまな作物の予測が可能

## セットアップ

### 1. リポジトリのクローン

```bash
git clone <repository-url>
cd forecast_growing
```

### 2. 仮想環境の作成（推奨）

```bash
python -m venv venv

# Windowsの場合
venv\Scripts\activate

# macOS/Linuxの場合
source venv/bin/activate
```

### 3. 依存パッケージのインストール

```bash
pip install -r requirements.txt
```

### 4. APIキーの設定

#### 必要なAPIキー

**Google Gemini API**
- [Google AI Studio](https://makersuite.google.com/app/apikey)でAPIキーを取得
- 無料枠あり

**Open-Meteo API**
- APIキー不要・完全無料
- 過去データと予報データの両方にアクセス可能
- https://open-meteo.com/

#### 環境変数の設定

`.env.example`をコピーして`.env`ファイルを作成：

```bash
cp .env.example .env
```

`.env`ファイルを編集してGemini APIキーを設定：

```
GEMINI_API_KEY=あなたのGemini APIキー
```

### 5. アプリケーションの起動

```bash
streamlit run app.py
```

ブラウザで自動的に開かない場合は、`http://localhost:8501`にアクセスしてください。

## 使い方

### ステップ1: 位置情報の設定

- **方法A**: 「位置情報を取得」ボタンをクリックしてGPSで自動取得
- **方法B**: 地名や住所を手動入力（例: Tokyo, 東京都渋谷区）

### ステップ2: 作物の情報入力

1. 作物の画像をアップロード（JPG、PNG形式）
2. 追加情報を入力（任意）
   - 例: 「種まきから2週間経過」「葉が少し黄色い」など

### ステップ3: 予測の実行

「収穫時期を予測」ボタンをクリックすると、以下の情報が表示されます：

- **作物分析**
  - 作物の種類
  - 現在の成長段階
  - 健康状態
  - 成長進捗度

- **収穫予測**
  - 予測収穫日
  - 収穫までの日数
  - 予測の信頼度
  - 予測の根拠

- **推奨事項とリスク要因**
  - 栽培上の推奨アクション
  - 注意すべきリスク要因

- **気温推移グラフ**
  - 過去7日間と今後7日間の気温変化

## 技術スタック

## トラブルシューティング

### APIキーエラー

```
❌ APIキーが設定されていません
```

→ `.env`ファイルを確認し、正しいAPIキーが設定されているか確認してください

### 位置情報が取得できない

- ブラウザの位置情報許可を確認
- または手動で地名を入力してください

### 画像分析が失敗する

- 画像が鮮明で作物がはっきり写っているか確認
- ファイルサイズが大きすぎないか確認（推奨: 5MB以下）

### 気象データ取得エラー

- 位置情報が正しいか確認
- インターネット接続を確認
- Open-Meteo APIが一時的にダウンしていないか確認
